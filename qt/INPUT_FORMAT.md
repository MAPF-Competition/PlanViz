# PlanViz input formats

Converter implementations and their documentation are now collected in
`src/planviz_qt/converters/`.

- [Converter development guide](src/planviz_qt/converters/README.md): supported
  inputs, the extension contract, an executable example, registration, and tests.
- [PlanViz JSON output specification](src/planviz_qt/converters/FORMAT.md):
  versioned fields, coordinate/action conventions, compressed motion, task/event
  records, and validation boundaries.
